# Модуль фильтрации и сравнения компьютерных комплектующих для интернет-магазина

Веб-приложение (REST API + простой интерфейс), которое позволяет покупателям фильтровать компьютерные комплектующие по множеству характеристик (цена, бренд, технические параметры) и сравнивать выбранные товары в наглядной таблице.

## Назначение

Модуль решает проблему поиска и выбора комплектующих (процессоров, видеокарт, материнских плат, оперативной памяти и т.д.) в интернет-магазине. Вместо ручного перебора страниц пользователь задаёт нужные параметры, а система мгновенно показывает подходящие товары. При сомнении можно добавить до 4 товаров в сравнение и увидеть их характеристики рядом.

## Возможности

1. **Фильтрация товаров**:
   - по категории (CPU, GPU, RAM, Motherboard и др.);
   - по цене (диапазон);
   - по бренду (Intel, AMD, NVIDIA, ASUS и т.д.);
   - по дополнительным характеристикам (количество ядер, частота, объём памяти, сокет и т.п.);
   - по текстовому поиску (название или описание).

2. **Сортировка результатов**:
   - по цене (возрастание/убывание);
   - по названию.

3. **Сравнение товаров**:
   - выбор до 4 товаров;
   - таблица сравнения с автоматическим подсветом лучших и худших показателей.

4. **Пагинация** (по 20 товаров на страницу).

5. **Веб-интерфейс** на Jinja2 + минималистичный CSS.

6. **REST API** для интеграции с любым фронтендом.

7. **Демонстрационные данные** – скрипт для заполнения базы тестовыми товарами.

## Технологии

- **Python 3.11+**
- **FastAPI** – веб-фреймворк
- **SQLAlchemy** – ORM
- **SQLite** – база данных (лёгкая, не требует отдельного сервера)
- **Pydantic** – валидация данных
- **Jinja2** – шаблонизатор для HTML
- **Uvicorn** – ASGI-сервер
- **pytest** – тестирование
- **Docker** (опционально)

## Установка и запуск

### Локальный запуск (без Docker)

Локальный запуск Клонируйте репозиторий и перейдите в папку проекта.

Создайте виртуальное окружение и активируйте его:

python -m venv venv
venv\Scripts\activate     

Установите зависимости:

pip install -r requirements.txt

Если файла requirements.txt нет, установите вручную:

pip install fastapi uvicorn sqlalchemy pydantic python-multipart aiofiles jinja2

Инициализируйте базу данных и загрузите демонстрационные настройки:

python scripts/init_demo_data.py

Запустите сервер:

uvicorn app.main:app --host 0.0.0.0 --port 8001

Откройте браузер по адресу http://localhost:8001.
